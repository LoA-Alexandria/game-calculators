# Signet Ring cost calculator

The calculator uses the level cost schedule pasted by the site owner on 1 October 2026. The game version and original effective date were not included with the schedule. The source records rounded values (including `k`, `m`, `b`, and `t` suffixes), so totals are estimates based on those displayed values.

For a range from level A to level B, the calculator adds the listed coin cost for each destination level from A+1 through B. An `ASCEND` ring cost shown after level N is included only when the selected target is above N. The supplied schedule covers levels 1–500; its 600-ring marker after level 500 is outside the supported range and is not included.

Update the source data and boundary tests together if a newer in-game schedule becomes available.
