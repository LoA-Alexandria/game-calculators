Worker cap = the highest number of worker slots a building of that family can reach, whatever its level. 0 means no ceiling – then the level table alone decides. A = Sandstone, Fish Pond, Flax Field, Papyrus, Mortar, Mudbrick · B = Gold, Natron, Drying Area, Hieroglyph Press. A single building can override it with its own limit in the type editor.

Off: workers and solver go for the most units. On: they go for the highest economic output, so a Gold Mine at 50 per unit outranks a Papyrus Workshop at 10. Displayed production stays in units either way.
